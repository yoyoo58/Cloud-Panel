# Cloud-Panel

YCloud est un mini cloud personnel développé avec **Node.js + Express** et un frontend simple en HTML/CSS/JS.

Il permet de gérer des fichiers et dossiers comme un petit Google Drive local.

---

# 🚀 Fonctionnalités

- 📁 Création de dossiers
- 📄 Upload de fichiers
- 🗂 Navigation dans les dossiers
- 🗑 Suppression fichiers / dossiers
- 👀 Ouverture des fichiers dans le navigateur
- ⚡ Interface web simple et rapide

---

# 🧱 Stack technique

- Backend : Node.js, Express
- Upload : Multer
- Frontend : HTML, CSS, JavaScript
- File system : fs (Node.js)
